# Supporto

Per domande, bug o richieste di funzioni apri una
[issue](https://github.com/LightYagami28/edex-ui/issues) usando i modelli
proposti.

Prima di aprirne una nuova controlla le issue esistenti e il file
[README.md](README.md).

Per le vulnerabilità non usare le issue pubbliche: segui
[SECURITY.md](SECURITY.md).
