# eDEX-UI nativo (.NET)

Riscrittura da zero di eDEX-UI in .NET, nativa per Windows, Linux e macOS, senza librerie di terzi.
Funzioni, architettura, struttura cartelle e piano sono in [SPEC.md](SPEC.md).

Rami: `native/base` (Core, test, CI), `native/windows`, `native/linux`, `native/macos`.

Il vecchio codice Electron è nella storia di `master`.
